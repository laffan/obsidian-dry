# D.R.Y. - Don't Repeat Yourself

An [Obsidian](https://obsidian.md/) plugin that highlights repeated words as you type.


### Usage

- **Keyboard shortcut**: Press the configured hotkey (default: can be set in Settings)
- **Command palette**: Open command palette (Cmd/Ctrl+P) and search for "Toggle D.R.Y. highlighting"

## Installation

1. Download the zipped [release](https://github.com/laffan/obsidian-dry/releases) file and unzip it. 
2. In Obsidian, navigate to Settings > Community Plugins. 
3. Click the folder icon above the "Installed plugins" list.  
4. Drag the unzipped release in to "plugins" folder.
5. Click the refresh icon above the "Installed plugins" list. 

You should see the plugin. Follow the same steps to update.
